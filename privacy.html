プライバシーポリシー（ドキマニア）

1. ゲームのデータと保存・削除

ゲームの進行データ（所持パーツ、設定など）はお使いの端末内にのみ保存され、開発者のサーバーへ送信されることはありません。開発者は、氏名・メールアドレス・連絡先などをアプリから自動収集しません。

ゲームの進行は、アプリの「せってい → データ初期化」で初期化できます。この操作では購入した石・パック等の権利と購入処理の記録を保持します。端末内のアプリデータを削除するには、iOSの設定から本アプリを「Appを削除」で削除してください（「Appを取り除く」はデータを残します）。端末のバックアップに含まれるデータは、iOS／iCloudの設定から管理・削除できます。開発者は端末内のデータを遠隔で削除できません。

2. 広告（Google AdMob）

本アプリには、プレイヤーが自分で選んだときだけ再生される「動画広告（ごほうび広告）」があります。広告の配信には Google LLC の AdMob を使います。広告はパーソナライズしない設定で、トラッキングの許可（ATT）は求めません。

広告の配信・不正防止・効果の計測・診断のために、Google が端末やアプリの情報（IPアドレス、端末の種類、おおまかな地域、アプリの利用状況、広告の表示・操作、障害や性能に関する情報など）を扱うことがあります。広告を再生しなくても、アプリ起動時の広告SDKの初期化等でGoogleとの通信が発生する場合があります。「広告を見なければ通信しない」という仕組みではありません。

Googleが扱う情報の保持期間・削除・プライバシーの管理は、Googleのプライバシーポリシー（https://policies.google.com/privacy）に従います。ごほうび広告は選ばなければ再生されず、見なくても遊べます。SDKを含む本アプリの通信を止めるには本アプリの利用を停止・削除してください。

不適切な広告・年齢に合わない広告は「せってい → 広告について → 不適切な広告を報告する」、またはごほうび広告の確認画面の「不適切な広告を報告」から報告できます。メールが使えない場合はサポートサイトの「広告の報告」欄が開きます。

3. アプリ内課金

石・パック・ドキパスの購入は Apple の App Store を通じて行われます。お支払い情報を開発者が受け取ることはありません。購入の記録はAppleが管理し、その保持・削除はAppleの方針と法令に従います。アプリの初期化や削除でAppleの購入履歴は消えず、サブスクリプションも解約されません。解約はiOSの「設定 → Apple Account → サブスクリプション」から行ってください。

4. Game Centerと同意の取り消し

Game Center にサインインしている場合、ランキングのスコアと実績が Apple の Game Center に送信されます。これは Apple のプライバシーポリシー（https://www.apple.com/legal/privacy/）に従って取り扱われます。連携を停止するにはiOSの「設定 → Game Center」からサインアウトしてください。Game Centerのデータの管理・削除に関するお問い合わせはAppleのプライバシー窓口をご利用ください。

5. 通知と同意の取り消し

通知はすべて端末内で予約されるローカル通知です。アプリの「せってい」のベルのスイッチ、またはiOSの「設定 → 通知 → ドキマニア」でいつでもオフにできます。通知の許可・拒否によって、ゲーム内の報酬や遊べる機能は変わりません。

6. 第三者による情報の保護

本アプリで利用する第三者サービス（Google AdMob、Apple App Store／Game Center）は、それぞれのプライバシーポリシーに基づき、本ポリシーおよび適用されるApp Storeのガイドラインと同等以上の個人データの保護を提供します。これには情報の安全管理、保持・削除、利用者のプライバシー管理手段が含まれます。第三者が扱う情報の詳細と権利の行使方法は、Google（https://policies.google.com/privacy）とApple（https://www.apple.com/legal/privacy/）の各ポリシーをご確認ください。

7. 子どものプライバシー

本アプリにチャット機能はありません。未成年の方が購入するときは、保護者の方の同意を得てください。iPhone の「スクリーンタイム」で購入を制限することもできます。

8. お問い合わせ・削除のご相談

本アプリ、不適切な広告、データの扱い・削除・同意の取り消しに関するお問い合わせは、leonbcgapartment@gmail.com までお送りください。お問い合わせでお送りいただいた返信先・内容は対応のためだけに利用し、対応に必要な期間保管した後、法令上の保存が必要なものを除き、不要になった情報を削除します。お問い合わせ情報の削除をご希望の場合も同じ窓口へご連絡ください。GoogleやAppleが管理する情報は、各社の窓口でのお手続きが必要な場合があります。
